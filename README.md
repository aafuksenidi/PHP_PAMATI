PRAKTISKAIS DARBS — PHP PAMATI
autors Aleksandrs Afuksenidi | 12, gr.

Projektā ir ietverta informācija par pieejamajiem kursiem. Var ievadīt grupas datus un saņemt informāciju par atlaidēm un cenām. Lietotāja ievadītie dati tiek pārbaudīti, vai nav kļūdu, un droši izvadīti, lai varētu veikt labojumus.

Datus var nosūtīt, lai sazinātos ar klientu.
